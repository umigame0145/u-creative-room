# 歩きスマホラッシュ / BUILD 03（簡易3D・ワザ）

2026-10-13更新。通常の体の接触でNPCが跳ね返り、得点が入るようにしました。ワザは「スマホ飛ばし」「おはじきアタック」の2種類です。

## 起動と操作

リポジトリのルートで npm run preview を起動し、http://127.0.0.1:4173/games/smartphone-rush.html を開きます。ホームと共通メニューからも開けます。公開・コミットはまだ行っていません。

- PC: WASD / 矢印キーで移動。Qでスマホ飛ばし、Eでおはじきアタック。Spaceは選択中のワザ、Pで一時停止・再開。
- スマホ: 画面・左下のパッドをドラッグして移動。右下のワザ1・ワザ2で直接発動。画面下のワザボタンでも発動します。
- ワザなしでも体が接触すればNPCが跳ね返り、通常の得点が入ります。遠くにいるNPCには当たりません。
- 60秒で終了。接触を2.4秒以内につなぐとコンボが続き、3回ごとに倍率が0.25増加（最大3倍）。

## ワザと得点

| アクション | 基本点 | スタミナ | 挙動 |
| --- | ---: | ---: | --- |
| 通常接触 | 50 | 0 | 体の接触でNPCが跳ね返る |
| ワザ1：スマホ飛ばし | 140＋破壊800 | 28 | 突進して接触。スマホが飛び、破損した画面・破片を表示 |
| ワザ2：おはじきアタック | 200 | 35 | 肩が当たった方向へNPCを10秒間飛ばす |
| おはじきのNPC連鎖 | 150 | 0 | NPC同士の衝突で反射し、巻き込んだNPCにも飛行を伝える |

点数にコンボ倍率を掛けます。スマホは各NPCが1台持ち、一度破壊すると同じスマホから破壊ボーナスを重ねて取れません。壁・柱の反射には得点を付けません。同じ接触を毎フレーム加点しない待ち時間があります。被害スコアはゲーム内の数値です。

おはじきは毎秒310の速度を保ち、壁・柱・NPC・プレイヤーに反射します。巻き込まれたNPCは元のNPCと同じ終了時刻まで飛びます。連鎖だけで10秒が延長され続けることはありません。別のワザで再び発射すると新しい10秒になります。一時停止中は飛行時間も停止します。

スタミナは毎秒19回復。ワザ1は0.9秒、ワザ2は1.2秒の共通待ち時間を設定しています。NPCの発射には0.24秒の踏み込み、スマホ飛ばしには0.32秒の突進があります。

## 実装

- u-t-on/games/smartphone-rush-engine.js: DOMに依存しないゲーム処理。2次元の床面上で円の衝突判定を行い、1/120秒以下の小刻みなステップで高速移動のすり抜けを防ぎます。位置の重なり補正と速度の反射を分け、加点待ち時間中も衝突処理を行います。
- u-t-on/games/smartphone-rush-3d.js: WebGLで駅・人物・スマホ・破片・飛行の軌跡を描画。固定の透視カメラと簡易ライティングを使用します。
- u-t-on/games/smartphone-rush.js: 入力、画面との接続、2D代替描画、結果と記録の保存。
- u-t-on/games/smartphone-rush.html / .css: 開始・操作・HUD・停止・結果画面。

移動と衝突判定は床面上の座標を使用し、上下階・ジャンプはありません。3Dを利用できない環境では2D表示になります。描画用の外部ライブラリ・画像は不要です。ベストスコアのみ smartphoneRushBest のキーで端末内に保存し、保存できない環境でも遊べます。

## 検証

npm test: 既存16件・ゲーム16件・3D3件の計35件に合格。通常接触、スマホの一度だけの破壊点、壁・柱・プレイヤーとの反射、NPCへの多段連鎖、10秒後の停止、一時停止時の飛行時計、身体の重なり、コンボ倍率と終了、ボタンとキー、保存不可などを検証しています。

npm run check: 構文・リンク・canonical・見出しの25件の検査に合格。

固定乱数で約56秒の連続操作・ワザ使用も検証し、位置と速度が有限の値を保つこと、全ての体の中心間距離が衝突半径の合計から0.1以内に収まることを確認しました。自動テストの描画部分は代替Canvas/WebGLです。ブラウザでもワザ2の発射・連鎖・反射、ワザ1の940点と破壊件数を確認しました。

スマホ実機の操作感・低速端末の性能・オンラインランキング・ステージ選択は未確認または未実装です。今後は背景・キャラクター・音・難易度・スコアの調整ができます。

## 2026-10-14 追加仕様

- 通常の体当たりは押し返し速度225、約0.38秒の小さなジャンプで「ポンっ」と弾む表現に変更。
- スマホ飛ばしのスマホは人（プレイヤーを含む）に当たると約0.8秒スピンさせ、ランダムな方向へ速度260で再発射。NPCはスピン中歩行を停止。
- 壁・柱で反射し、発射から8秒間連鎖可能。命中で寿命は延長しない。連鎖による追加得点はなし。
- 直前に当たった人から離れるまで再命中しない。一時停止中はスマホとスピンも停止。再プレイでリセット。
- 3Dと2D代替表示にジャンプ・スピンを反映。新しい動作のテスト2件を追加。

## 2026-10-15 コンボ強調・虹色暴走

- コンボ数が増えると数字が拡大して戻る。ゲーム画面内のCOMBOも短く拡大。動きを減らす設定では拡大アニメーションを停止。
- 同じNPCにスマホ飛ばし・おはじきアタックを両方当てると虹色暴走。順序は不問。同じワザだけでは発動しない。
- 2つ目のワザから、そのNPCへの加点はコンボ倍率に加えて2倍。ラウンド終了まで回転・ジャンプ・反射を続ける。3D・2Dとも虹色を表示。
- 一時停止で暴走も止まり、再プレイで解除。自動テスト39件、サイト検査25件に合格。
