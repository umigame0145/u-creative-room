# 実出力サンプルの制作記録

制作日：2026-10-26。対象：画像結合・画像梱包（PDF）。未公開のローカル変更。

- 入力素材は今回の説明用に新規作成した架空の創作メモ。第三者の画面・写真や個人情報は使用していない。
- sample-plan.png / sample-check.png / sample-share.png は600×400、300×400、600×400px。
- 結合結果はブラウザ上の画像結合ツールで上記の先頭2枚を読み込み、縦・白背景・PNG、none/max/minを選んで作成し、保存ボタンからダウンロード。
- PNGの保存はBlob方式へ変更。実ダウンロード成功、エンコード失敗時の案内をテストした。
- join-none.png=600×800、join-max.png=600×1200、join-min.png=300×600を画像ファイルから確認。
- PDFは同じブラウザ上の画像梱包ツールに3枚を順に読み込み、A4/10mm、A4/0mm、B5/10mmの中央配置で保存ボタンから取得。全て3ページ。
- PDFはPopplerで全9ページをレンダリングして確認。pypdfでA4=595.28×841.89pt、B5=515.91×728.50ptを全ページ確認。
- pdf-*.png はPDFの1ページ目をPopplerでレンダリングしたプレビュー。見た目を別途再現した画像ではない。
- join-settings.webp / pdf-settings.webp は実際の操作画面のスクリーンショットをWebPへ変換したもの。UIの合成や架空の結果を挿入していない。
- 元画像・PNG実出力・PDFはページからダウンロード可能。設定と注意点、文字の読める大きさや画像比率による余白を説明。
- ブラウザでPC表示とスマホ幅375pxの表示を確認。両ページともdocumentElementのscrollWidth/clientWidthが375/375で横にはみ出さないことを確認。
- ローカルプレビューでPDFとWebPのMIMEを明示するよう変更。

検証：npm test 45件、npm run check 26件。公開・AdSense再申請はしていない。
