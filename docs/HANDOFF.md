- 小さな改善を1回に1つずつ commit → push → 公開し、「継続的に手入れされている」状態を作る。
- 既存ツールすべてに出力例・具体的な使い方・関連記事リンク（2026-11 に完了）。
- 悩み解決型の読み物を合計10本ほど追加する（2026-11-21 時点で新規2本）。
- 新ツールは2週間に1つ公開（下の予定表）。
- 約1か月更新を続けてから（12月中旬めど）再審査を申請する。それまで「問題を修正しました」にはチェックしない。
- 新ツールはオーナーがプレビューを確認してからマージする。記事の追加・改善は作業者がマージしてよい。

## 作業ルール
- 新ツールは既存のあみだくじと同じ構成・デザインに合わせる（`site-data.js`、`index.html`、`sitemap.xml`、アイコン、テスト、出力例・使い方・関連リンク）。
- 名前や素材は架空・ダミーのみ。一次資料リンクは実在を確認できたものだけ。
- CSP の都合でインラインスクリプトは禁止（外部 .js を使う）。
- `npm test` と `npm run check` を必ず通す。
- コミット作者: `git -c user.name=umigame0145 -c user.email=030b04@gmail.com commit ...`
- PR を重ねると `u-t-on/sitemap.xml` で競合しやすい。mainにrebaseし、URL行はすべて残す。
- `adsense-review.md`（ローカルのみの検討メモ）と `scripts/__pycache__` はコミットしない。
- 画面確認はヘッドレスChrome: `google-chrome --headless=new --no-sandbox --window-size=820,1100 --virtual-time-budget=3000 --screenshot=out.png <URL>`
