# 動画コマ分解

実装日：2026-11-03。`u-t-on/tools/video-frames.html`。以下は公開前の実装・検証記録。

## 操作

- 全フレーム / 指定間隔（0.01秒以上）、開始を含み終了を含まない範囲。
- 実フレーム順のコマ送り、任意の1枚保存、PNG / JPEG（画質選択）。
- 1回200枚。超過分は明示した「続きの200枚」で置き換え。保存を先に案内する。
- ZIP内に画像と`frames.csv`（連番、相対時刻、ソースPTS、継続時間、ファイル名）。単独CSV保存も可能。
- 抽出結果は横スクロールのフィルムストリップ。画像部分/チェックボックスで任意の複数コマを選択し、選択分だけをZIP保存（CSVも選択分だけ）。全選択・選択解除・全画像ZIPも併設。選択は表示順で保存し、次の抽出や消去でリセット。保存処理中は選択を固定。
- 一覧JPEGは低解像度サムネイルを1枚ずつ描画。最大1000×5840px。
- 自作の240フレーム / 8秒 / 640×360pxのサンプルで手元の動画なしでも試せる。

## 復元・負荷制御

- Mediabunny 1.65.0を無変更で同梱。MPL-2.0ライセンスとソース入りの元npmアーカイブも公開ディレクトリに同梱。固定ハッシュをテスト。
- MP4 / QuickTime / WebMのみ。BlobSourceのキャッシュ4MiB。映像・画像をアップロードしない。
- パケットのPTSをメタデータだけで索引化し、表示順にソート。固定FPSや再生スクリーンショットは使わない。
- CSVの継続時間は次の表示PTSとの差分（最後はパケットの継続時間）。VFR/Bフレームのデコード順の時間差と混同しない。
- WebCodecsによる復元。通常は連続samples、間隔指定でフレームが離れる場合はsamplesAtTimestampsを使う。
- コマ送りは元PTSの直後を照会する。丸めてから照会すると前のパケットが選ばれる不具合があるため、元PTSに0.51μsを加算。取得PTSは0.51μs許容で検証。
- 重複・非有限PTS、マイクロ秒精度で区別不能なPTSは拒否。復元順序/枚数が合わない場合は成功扱いにせず、保存可能な途中分のみ残す。
- 入力512MiB・12万パケット・長辺4096pxかつ4096×2160画素以下。出力長辺1920px以下（初期値1280px、拡大なし）。
- 保持画像96MiBまで。到達時は次の未出力フレームから続けられる。枚数だけではメモリ上限にならないため容量も制限。
- 1枚ずつ画像化してVideoSample.close()。ギャラリーは長辺160pxのサムネイルのみ描画。Blob URLは結果置換・消去・pagehideで解放。
- ZIPはSTORE方式。圧縮済み画像を再圧縮せず、CRC計算時のArrayBufferを1枚ごとに破棄。Blobを組み合わせる。端末・ブラウザの実装によるコピーやデコーダー内部メモリはあるため、低メモリ端末での成功を保証しない。
- 中止時は処理完了分を残して、続きの復元が可能。エンコーダーエラー時もサンプルを解放。

## 検証

`npm test` 65件成功。`npm run check` 30ページ・スクリプトおよび全ローカルリンク成功。

横スクロール/選択追加時の検証：任意の3枚（1,61,181コマ目）を実画面から選び、ZIP内にその3枚と対応するCSVだけが入ることを独立検証。選択順が前後しても保存は元の順。選択なし・全選択・解除・結果置換・保存中の選択固定を回帰テスト。

- 自動テスト：計画、VFR/Bフレーム順、境界、200枚と続き、解像度、ZIP構造・CRC・UTF-8名、容量制限、中止、欠落フレーム、エンコード失敗と再試行、Blob URL解放、実サンプルのパケット解析。
- Chromium（Brave / アプリ内ブラウザ）で実ファイルを操作。CFR240枚を200+40枚でZIP保存し、全画像のCRCと画像デコード、CSV連番・PTSに欠落/重複がないことを確認。
- VFR150枚を全抽出し、FFmpegの独立デコードと全PTSを照合。コンテナ編集リストで最後の1コマがトリミング扱いになるfixtureのため、独立検査は`-ignore_editlist 1`で保存された全フレームを対象にした。
- CFRの1,2,60,61,200,201,240枚目をFFmpegのPNG出力と比較。RGB平均絶対誤差0.343〜0.352/255で、対応するフレームの内容を確認（色変換の違いがある）。
- 1秒間隔のJPEG8枚、VP9 WebMの0.5秒間隔16枚、回転MP4の360×640px、0〜0.2秒の全6枚、コマ送りと単独保存、一覧画像1000×1168pxを実操作で確認。
- 実効ビューポート360px / 1265pxで横はみ出しなし。iOS/Android実機・Safari/Firefoxは未検証。全コーデックやHDR忠実再現は保証しない。
